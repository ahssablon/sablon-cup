Tempel Konfigurasi Firebase Anda

Aplikasi ini sudah siap terhubung secara real-time multi-device ke Cloud Firestore & Login Admin. Anda hanya perlu menempelkan kode firebaseConfig dari Firebase Console ke dalam file index.html ini:

  1. Buka Firebase Console → klik ikon gerigi Project Settings.
  2. Gulir ke bawah ke bagian Your apps, klik ikon Web (</>) dan salin objek firebaseConfig.
  3. Buka file index.html ini di editor teks/GitHub, cari bagian KONFIGURASI FIREBASE di bagian atas script, lalu ganti nilai placeholder dengan konfigurasi milik Anda.
  4. Simpan file dan muat ulang (refresh) halaman ini.
Tips: Pastikan fitur Authentication (Email/Password) dan Firestore Database sudah diaktifkan di proyek Firebase Anda.
